# Montserrat

The unmodified Montserrat Regular and Bold static TrueType fonts are bundled for offline use in the documentation panel. No system installation is required.

Source: [The Montserrat Project](https://github.com/JulietaUla/Montserrat/tree/555facfb2a18c72c3c0380f0d9c0f060453a9058), commit `555facfb2a18c72c3c0380f0d9c0f060453a9058`.

- `fonts/ttf/Montserrat-Regular.ttf`
- `fonts/ttf/Montserrat-Bold.ttf`

Copyright and redistribution terms are included in `OFL.txt` from the same source revision. Retain it when distributing these fonts with the plugin.
